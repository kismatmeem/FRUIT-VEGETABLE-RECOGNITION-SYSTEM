# Fruit and Vegetable Detection with Calorie Estimation

This project detects fruits and vegetables from an input image using a deep learning model and displays the predicted food name along with its calorie information.

## Project Files
- fruit_veg_recognition.ipynb  
  Used for training the fruit and vegetable classification model.

- ModelTest.ipynb  
  Used for testing the trained model on a single image and showing the predicted food label and calories.

## Dataset
The dataset used for this project was collected from Kaggle.
The dataset is not included in this repository due to its large size.

## Output
The system takes a food image as input and outputs:
- Predicted fruit or vegetable name
- Corresponding calorie value

## Tools Used
- Python
- TensorFlow / Keras
